# 02-Products

Contains the product catalog data and categories for the GreenBasket storefront.

## Files
- `products.js`: Exports `categories`, `initialProducts`, and `products`.
  - Categories: Vegetables, Fruits, Herbs & Greens, Dairy & Eggs, Nuts & Seeds.
  - Fields per product: `id`, `name`, `unit`, `price`, `category`, `rating`, `reviews`, `stock`, `image`, `tag`.
