# Deployment (GitHub + Vercel)

1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Run `npm install` then `npm run dev`.
4. Push the complete project to a GitHub repository.
5. In Vercel, import that repository.
6. Use the default Vite build command `npm run build` and output directory `dist`.
7. Deploy and open the URL Vercel provides.
