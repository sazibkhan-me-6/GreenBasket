# 05-Admin-Panel

Contains the administrative store management dashboard.

## Files
- `AdminModal.jsx`: Administrative modal dashboard featuring:
  - Metric counters: Total Products, Total Orders, Total Sales Revenue, and Active Customers
  - Product Catalog Management: view all products, add new items with price/category/stock/image, and delete items
  - Customer Orders Table: live list of placed orders with customer details, delivery address, payment method, order total, and status
