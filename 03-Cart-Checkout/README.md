# 03-Cart-Checkout

Contains the cart drawer and basket management component.

## Files
- `CartDrawer.jsx`: Interactive side-drawer showing:
  - Added products with thumbnail, title, price, and unit
  - Increment, decrement, and item removal controls
  - Promo discount code input (e.g. `GREEN20` for 20% off)
  - Subtotal, discount deduction, delivery fee (Free over $49) and grand total calculation
  - One-click trigger to launch the checkout modal
