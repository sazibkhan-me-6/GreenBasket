# 07-Payment

Contains the checkout and payment processing modal.

## Files
- `CheckoutModal.jsx`: Interactive checkout modal featuring:
  - Shipping address form (Recipient name, phone, full delivery address, delivery instructions)
  - Payment method options:
    - Cash on Delivery (COD)
    - Debit / Credit Card (Visa, Mastercard, Amex demo)
    - Mobile Banking (bKash, Nagad, etc.)
  - Order recap with items, subtotal, delivery fee, and total
  - Instant order placement and order confirmation receipt screen with order ID tracking
